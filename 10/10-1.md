# Step-by-Step Breakdown of 10/10-1.py

This script demonstrates how to fine-tune a pre-trained BERT model using the `sentence-transformers` library for a classification task and then evaluate its performance on semantic similarity and MTEB benchmarks.

## 1. Data Preparation
* **Dataset Loading**: Loads the **MNLI** (Multi-Genre Natural Language Inference) dataset from the GLUE benchmark.
* **Subsetting**: Takes a subset of 50,000 examples to manage computational load.
* **Column Reordering**: Reorders the dataset columns to `['hypothesis', 'premise', 'label']`.

## 2. Model & Loss Setup
* **Base Model**: Loads the `bert-base-uncased` model using the `SentenceTransformer` class.
* **Loss Function**: Defines a **`SoftmaxLoss`** function. This is used to train the model to classify input pairs into one of three categories: *entailment*, *neutral*, or *contradiction*.

## 3. Evaluation Setup
* **Similarity Evaluator**: Prepares an **`EmbeddingSimilarityEvaluator`** using the **STSB** (Semantic Textual Similarity Benchmark) dataset. This measures how well the model's embeddings capture semantic similarity via cosine similarity.

## 4. Training
* **Trainer**: Uses the `SentenceTransformerTrainer` to fine-tune the BERT model on the MNLI dataset for one epoch.
* **Training Arguments**: Configures parameters such as batch size, learning rate (via warmup steps), and mixed-precision training (`fp16=True`).

## 5. Evaluation
* **Internal Evaluation**: Runs the `EmbeddingSimilarityEvaluator` on the trained model using the STSB dataset.
* **Benchmark Evaluation**: Uses the **MTEB** (Massive Text Embedding Benchmark) library to evaluate the model on the `Banking77Classification` task.
