# Documentation: 07-01.py

This script performs local LLM inference using the `LlamaCpp` class from `langchain_community`. It loads a specific GGUF model (Microsoft Phi-3-mini) and uses the GPU for inference to answer a predefined question.

## Libraries Used

- `rich.console.Console`: Used for stylized terminal output (e.g., printing with specific colors like `gold1`).
- `langchain_community.llms.LlamaCpp`: The primary interface for interacting with the Llama.cpp backend to load and run the model.

## Variables

- `MODEL_PATH`: A string containing the absolute/relative path to the `.gguf` model file (`../models/Phi-3-mini-4k-instruct-fp16.gguf`).
- `console`: An instance of `rich.console.Console` for formatted printing.
- `model`: An instance of `LlamaCpp` representing the loaded LLM.
- `question`: The string containing the user input/query used for the prompt.
- `prompt`: The formatted string containing the ChatML-style template (`<|user|>\n...\n<|assistant|>\n`) required by the Phi-3 model.
- `response`: The string returned by the `model.invoke()` method containing the model's generated text.
- `key`: Stores the user input from the terminal to pause the script execution.

## Main Objects and Functions

### `LlamaCpp` (Object)
The core object used for model orchestration. 
**Parameters used in constructor:**
- `model_path`: Path to the GGUF model.
- `n_gpu_layers`: Set to `-1` to offload all layers to the GPU.
- `max_tokens`: The maximum number of tokens to generate (1024).
- `n_ctx`: The context window size (4096).
- `seed`: The random seed for reproducibility (42).
- `verbose`: Set to `False` to suppress detailed backend logs.

### `model.invoke(prompt)` (Method)
Executes the inference process by passing the formatted `prompt` to the loaded model and returning the generated text response.

## Resources Used

- **Model File**: `../models/Phi-3-mini-4k-instruct-fp16.gguf` (Microsoft Phi-3-mini, 3.8B parameters, FP16 precision).
- **Hardware**: Requires GPU support (configured via `n_gpu_layers=-1`).


from langchain_community.llms import LlamaCpp    La convención para nombres de clase es CamelCase (también llamado PascalCase)

MODEL_PATH = "../models/Phi-3-mini-4k-instruct-fp16.gguf"   Por convención, las variables que son constantes se definen con nombre en todo mayúsculas

model = LlamaCpp(model_path=MODEL_PATH, n_gpu_layers=-1, max_tokens=1024, n_ctx=4096, seed=42, verbose=False)
