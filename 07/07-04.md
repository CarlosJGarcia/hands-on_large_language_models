# Documentation: 07-04.py

This script demonstrates how to use LangChain to implement a basic conversational memory mechanism. It uses a `PromptTemplate` to incorporate chat history into the prompt and leverages LangChain's pipe operator (`|`) to create a runnable chain consisting of a prompt and the `LlamaCpp` model.

## Libraries Used

- `rich.console.Console`: Used for stylized terminal output (e.g., printing with specific colors like `gold1`).
- `langchain_community.llms.LlamaCpp`: The primary interface for interacting with the Llama.cpp backend to load and run the model.
- `langchain_core.prompts.PromptTemplate`: Used to define a reusable prompt template that can accept dynamic input variables like `chat_history` and `texto`.
- `langchain_core.output_parsers.StrOutputParser`: (Imported, though the chain in this script currently returns the raw model output).
- `langchain_core.runnables.RunnablePassthrough`: (Imported, used for passing data through the chain).

## Variables

- `MODEL_PATH`: A string containing the absolute/relative path to the `.gguf` model file (`../models/Phi-3-mini-4k-instruct-fp16.gguf`).
- `chat_history`: A string intended to store the accumulated conversation history (initialized as an empty string).
- `console`: An instance of `rich.console.Console` for formatted printing.
- `model`: An instance of `LlamaCpp` representing the loaded LLM.
- `template`: The string defining the ChatML-style template structure, including placeholders for `{chat_history}` and `{texto}`.
- `prompt`: A `PromptTemplate` object created from the `template` string.
- `chain`: A LangChain runnable object created by piping the `prompt` into the `model`.
- `question`: The string containing the user query (e.g., "Hi! My name is Carlos...").
- `response`: The string returned by the `chain.invoke()` method containing the generated response.

## Main Objects and Functions

### `LlamaCpp` (Object)
The core object used for model orchestration.
**Parameters used in constructor:**
- `model_path`: Path to the GGUF model.
- `n_gpu_layers`: Set to `-1` to offload all layers to the GPU.
- `max_tokens`: The maximum number of tokens to generate (1024).
- `n_ctx`: The context window size (4096).
- `seed`: The random seed for reproducibility (42).
- `verbose`: Set to `False` to suppress detailed backend logs.

### `PromptTemplate` (Object)
Defines how the input variables are formatted into a single string for the model.
**Parameters used in constructor:**
- `template`: The raw string template containing variable placeholders.
- `input_variables`: A list of strings identifying the variables to be interpolated (e.g., `["texto", "chat_history"]`).

### `chain.invoke({...})` (Method)
Executes the chain by passing a dictionary of input values. It processes the `prompt` with the provided `texto` and `chat_history`, then passes the result to the `model` to obtain a response.

## Resources Used

- **Model File**: `../models/Phi-3-mini-4k-instruct-fmt16.gguf` (Microsoft Phi-3-mini, 3.8B parameters, FP16 precision).
- **Hardware**: Requires GPU support (configured via `n_gpu_layers=-1`).

## Code Notes and Conventions

```python
from langchain_core.prompts import PromptTemplate   # Import template class
prompt = PromptTemplate(template=template, input_variables=["texto", "chat_history"])  # Create template
chain = prompt | model  # Using the pipe operator to chain components
```
