Why is it getting slower?
The Xeon E5-1620 v3 has 4 cores. The process is like this
	1.	Preprocessing (CPU): Tokenizing 8,500 strings into tensors.
	2.	Transfer (Bus): Moving those tensors from RAM to the GPU.
	3.	Inference (GPU): The RTX 3060 doing the math.
	4.	Post-processing (CPU): Turning those logits back into "Positive/Negative" labels.

- CPU Exhaustion: Because the CPU  only has 4 cores, preprocesing takes longer than processing in the GPU
- GPU Wait: The RTX 3060 finishes a batch and then sits there doing nothing while the 4-core CPU prepares the next (batch size) items.
